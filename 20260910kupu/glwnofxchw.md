# 妇幼医院孕12周先建档还是先nt？

> 更新时间：2026-09-10 (UTC+8)

妇幼医院孕12周先建档再nt。因为妇幼医院建档时间一般要比nt检查时间提前半个月或者是更早，其建档的目的就是能很方便地了解胎儿从怀孕开始到出生的整个生理状态，里面记载了孕妇的基本信息以及怀孕过程的所有信息，因此很多妇幼医院都是先让孕妇先建档再做nt检查。当然患者除了需要了解先建档还是先nt外，还可以了解一下建档的流程。

## 产检建档流程

建档是指孕妇在怀孕12周左右前往医院建立一个孕期档案，这个档案中记录了孕妇的基本信息以及怀孕过程中所有的检查时间、项目、预产期等信息，还包括了孕期妈妈必知的一些知识，其流程一般分为5个步骤。

- 1. 第一次挂妇科号并告知医生建档需求，医生给开单做检查，当天必须空腹，检查项目有很多，包括血HCG+孕酮+B超，确定宫内早孕的话去找医生看结果，医生还会给开建档检查其他必须项目，如血常规+血型(ABO和RH）、尿常规、血生化A(肝、肾功能+空腹血糖、甲功以及白带，一般建议第一次去医院建议6周左右，B超就能照出胎心胎芽了；
- 2. 怀孕满6周之后去所属的社区医院办理母子健康档案，孕妇可根据居住地/户口所在地即可查询《母子健康手册》《生育登记服务单》办理具体地点、所需材料、办理流程、咨询电话等；挂妇科号就诊，携带第一次所有检查结果，B超要有胎心胎芽，妇科医生诊治完毕，评估是否可以在本院建档，如果可以建档，大夫在病历本上面写上建档，然后持孕妇本人身份证及母子健康档案打印完所有的就诊发票，到妇科分诊台建档处正式建档；
- 3. 正式建档一周内，第三次挂妇科早孕号就诊，不需要空腹(大夫有特殊医嘱除外)，检查艾梅乙(免费)+乙肝四项+丙肝，不用等检查结果，如有异常会电话通知孕妇来院；
- 4. 到产筛就诊前，请将艾梅乙化验结果打印(此结果三天后出来)，把结果交给产筛大夫诊治否则医生不予接诊。

一般来说，妇幼医院孕12周是先建档在nt。其实很多医院都会将建档的时间安排在nt检查前的半个月或是更久。若是医院人不多的话，那么孕12周的时候，可能就会将nt和建档一起做。
